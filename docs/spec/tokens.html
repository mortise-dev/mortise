Four rules that come with the values.

  1. ink-3 never on frame. It is 4.13 to 1 there in the light theme, under the 4.5 limit for text. off has the same value and the same rule.
  2. warn never as text on frame: 4.40 to 1 in the light theme.
  3. line-2 never as the outline of a control on frame: 2.84 to 1 in the light theme, under the 3 to 1 limit for marks. Rail tiles and the search entry in the title bar use ink-2 for their outline. This is a change to the identity stylesheet, made necessary by the Slate values. The owner accepted it on 22 November 2026; it is a rule, not a question.
  4. Colour is only state. Good, warn, bad and off are the only chromatic values in the interface. key-hover and key-press are ink mixed 16% and 30% toward surface.

3.6 Motion

TokenValue
motion.selection0 ms. Row, tab, palette row and theme change redraw in the same frame.
motion.overlay-open0 ms. Palette, dialog and tooltip appear and go without a transition.
motion.drawer120 ms, ease out. Height of the runner drawer.
motion.created-file600 ms, linear. Well fill behind a new file fades to none.
motion.toast-in120 ms, ease out. Slides 8 px up.
motion.toast-out160 ms, ease in. Fades.
motion.toast-dwell4000 ms for done and note. A failed toast stays until closed.
motion.tooltip-delay500 ms after the pointer rests. 0 ms on keyboard focus.
motion.reducedWith reduced motion every duration above is 0 ms, except toast-dwell and tooltip-delay.

Nothing moves unless the user or a command caused it. No hover transitions, no loops, no spinner: a running command shows elapsed time counting, and work of known size shows a bar.
