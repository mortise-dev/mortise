8. Platform notes

The slim title bar is 34 px high and belongs to the window frame colour. It always holds the same three things: the mark with the name on the left, the entry to the command palette in the middle, the current app and how its PHP runs on the right. Only the window controls differ.

T1macOS

The three window buttons are drawn by macOS at the left, at their normal place. Mortise leaves 78 px free for them and starts the mark after that.

Minimise, maximise and close at the right, 44 px wide each, full height of the bar, drawn by Mortise. All three take the well fill on hover; close is not red, because colour is kept for state.

MortiseSearch or run a commandCtrl Kshop-api on Herd

T3Linux

The same three controls drawn by Mortise, on the right by default. A setting moves them to the left for desktops that put them there.

T4Fallback: the platform's own title bar

Where a custom title bar is not possible, the window keeps the platform's bar (grey here, not designed by Mortise) and the Mortise bar sits directly under it, unchanged except that it holds no window controls.

10. Interface text

Voice. Plain and concrete, like a note left on a workpiece: what happened, to what, and what was left untouched. Sentence case. No exclamation marks, no apology, no "please". An action keeps one name from the button to the confirmation to the message: "Turn off", "Turn off Checkout?", "Turned off Checkout." An error says what happened, then what to do next. Text that comes from PHP, the database or the package is quoted as it is and never rewritten.

Two words that must not meet. Findings (problem, warning, good) are what Mortise works out from the files. Runtime (Up, Down, Out of service, Unknown) is what the running app reports through the actuator. The word "health" appears in the interface only inside a path or a config key the user must type. "On" and "Off" are a module's state in modules_statuses.json, and "Turn on" and "Turn off" are the actions; the artisan names module:enable and module:disable appear only in the command preview.

The drawings read their strings from this table, so what is listed here is what is drawn. Names in the examples (shop-api, Checkout, counts) are placeholders for real values.

11. Fonts

Both families will be bundled inside the app, so their licences were read in each font's own repository on 22 November 2026, not recalled. Both are free to bundle.

Inconsolatagithub.com/googlefonts/InconsolataOFL.txt on branch mainSIL Open Font License, version 1.1Copyright 2006 The Inconsolata Project Authors (https://github.com/cyrealtype/Inconsolata)None declared in the copyright line

What the licence allows and asks, from the text of the two files, which is the same from "PERMISSION & CONDITIONS" on:

  • Condition 2: the fonts "may be bundled, redistributed and/or sold with any software, provided that each copy contains the above copyright notice and this license". They "can be included either as stand-alone text files, human-readable headers or in the appropriate machine-readable metadata fields within text or binary files as long as those fields can be easily viewed by the user".
  • Condition 1: the fonts may not be sold by themselves. Bundling them in an app, free or paid, is not that.
  • Conditions 3 and 4: a modified version may not use a reserved font name, and the authors' names may not be used to promote it. Neither file declares a reserved name. Subsetting a font is a modification, so if the builders subset, they should keep the original family names only because no name is reserved; if a later release of either font declares one, a subset must be renamed.
  • Condition 5: the fonts stay under this licence. The app itself can have any licence.

What the app must do. Ship both OFL.txt files with their copyright lines, for example in a licenses folder next to the binary and on an "About" line in Settings. Leave the licence metadata inside the font files as it is.

Notes. The address in Inconsolata's copyright line, github.com/cyrealtype/Inconsolata, now redirects to the Google Fonts repository linked above. Which files to bundle: the static weights 400, 500, 600 and 700 of Asap and 400, 500 and 600 of Inconsolata, at normal width. Whether egui renders the variable versions was not checked, so static files are the safe choice. No replacement is needed, so none is proposed.
