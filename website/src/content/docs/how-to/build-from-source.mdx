Build Mortise yourself to run a version that has no release, or to work on it.
To install a release instead, see [Install Mortise](/mortise/start-here/installation/).

## Run Mortise from source

<Steps>

1. Install [rustup](https://rustup.rs). Mortise needs Rust 1.100. The file `rust-toolchain.toml` in the repository selects it, and rustup installs it on the first build.

2. On Linux, install the libraries the window needs. On Debian and Ubuntu:

   ```sh
   sudo apt-get install -y libxkbcommon-dev libwayland-dev
   ```

   macOS and Windows need nothing more.

3. Clone the repository:

   ```sh
   git clone https://github.com/mortise-dev/mortise.git
   cd mortise
   ```

4. Run Mortise. The path of a Laravel app is optional:

   ```sh
   cargo run -p mortise-app -- /path/to/laravel-app
   ```

</Steps>

The window opens. Its binary is `mortise-desktop`. For a build without the debug checks, add `--release` after `run`.
To keep the settings of this build apart from those of your installed Mortise, see the environment variables in [Files and folders](/mortise/reference/files-and-folders/).

## Build the command line tool

The command line tool is the binary `mortise`, in the crate `mortise-cli`. It needs no window
libraries. Run it from the clone:

```sh
cargo run -p mortise-cli -- check /path/to/laravel-app
```

Or install it on your path:

```sh
cargo install --locked --path crates/mortise-cli
```

See [Command line tool](/mortise/reference/command-line/) for what it prints.

## Build the installers

<Steps>

1. Install cargo-packager, at the version the project uses:

   ```sh
   cargo install cargo-packager --locked --version 0.11.8
   ```

2. Build the installers of your platform. cargo-packager builds Mortise in release mode first.

   <Tabs syncKey="os">
   <TabItem label="macOS">
   ```sh
   cargo packager -p mortise-app --release --formats app,dmg
   ```
   A local build is signed ad hoc, not with a Developer ID.
   </TabItem>
   <TabItem label="Windows">
   ```sh
   cargo packager -p mortise-app --release --formats nsis
   ```
   The setup is not signed.
   </TabItem>
   <TabItem label="Linux">
   ```sh
   cargo packager -p mortise-app --release --formats appimage,deb
   ```
   The release builds these on Ubuntu 22.04. They are not signed.
   </TabItem>
   </Tabs>

</Steps>

The installers are in `target/packages`.
