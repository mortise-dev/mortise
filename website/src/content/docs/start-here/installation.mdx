Install Mortise from a release. To build it yourself, see [Build Mortise from source](/mortise/how-to/build-from-source/).

<Steps>

1. Open the [latest release](https://github.com/nWidart/mortise/releases/latest).

2. Download the file for your platform and the sums file `Mortise-vX.Y.Z-SHA256SUMS.txt`, into the same folder.

   | Platform | File |
   |---|---|
   | macOS, Apple silicon | `Mortise-macos-arm64.dmg` |
   | Windows, x64 | `Mortise-windows-x64-setup.exe` |
   | Linux, x86_64 | `Mortise-linux-x86_64.AppImage`, or `Mortise-linux-amd64.deb` for Debian and Ubuntu |

3. Check the SHA-256 sum. Run the command in the folder of the downloads, with the version of the release in place of `vX.Y.Z`.

   <Tabs syncKey="os">
   <TabItem label="macOS">
   ```sh
   shasum -a 256 -c --ignore-missing Mortise-vX.Y.Z-SHA256SUMS.txt
   ```
   The line of the DMG must end in `OK`.
   </TabItem>
   <TabItem label="Windows">
   In PowerShell:
   ```powershell
   (Get-FileHash -Algorithm SHA256 .\Mortise-windows-x64-setup.exe).Hash.ToLower()
   Select-String Mortise-windows-x64-setup.exe .\Mortise-vX.Y.Z-SHA256SUMS.txt
   ```
   The two sums must be the same.
   </TabItem>
   <TabItem label="Linux">
   ```sh
   sha256sum -c --ignore-missing Mortise-vX.Y.Z-SHA256SUMS.txt
   ```
   The line of your file must end in `OK`.
   </TabItem>
   </Tabs>

   If a sum differs, delete the file and download it again.

4. Install Mortise.

   <Tabs syncKey="os">
   <TabItem label="macOS">
   Open the DMG and drag Mortise to the Applications folder. The app is signed with a Developer ID and notarized by Apple, so macOS opens it without a warning.
   </TabItem>
   <TabItem label="Windows">
   Run `Mortise-windows-x64-setup.exe`. The installer is not signed, so SmartScreen warns once. Choose **More info**, then **Run anyway**.
   </TabItem>
   <TabItem label="Linux">
   For the AppImage, make the file executable, then run it:
   ```sh
   chmod +x Mortise-linux-x86_64.AppImage
   ./Mortise-linux-x86_64.AppImage
   ```
   For the .deb, install it with apt:
   ```sh
   sudo apt install ./Mortise-linux-amd64.deb
   ```
   Neither file is signed.
   </TabItem>
   </Tabs>

5. Start Mortise. The first window says **No apps yet** and offers **Add app folder**.

</Steps>

Mortise is installed. To open your first app, go on to [First steps](/mortise/start-here/first-steps/).
Where Mortise keeps its settings and its history is in [Files and folders](/mortise/reference/files-and-folders/).

## Install the command line tool

The command line tool, binary `mortise`, runs `mortise check` and `mortise push` in CI or in a
terminal. It is not in the installers above. Get it one of three ways.

### In GitHub Actions

The action [`nwidart/setup-mortise`](https://github.com/nWidart/setup-mortise) downloads the tool for
the runner, checks its SHA-256 against the sums of the release, and puts it on `PATH`. It needs no
Rust toolchain.

```yaml
steps:
  - uses: actions/checkout@v5
  - uses: nwidart/setup-mortise@v1
  - run: mortise check . --format github
```

It runs on Linux (x64 and arm64), macOS (Apple silicon) and Windows (x64) runners. Without
`version` it installs the latest release; `with: { version: v0.3.0 }` pins one.

### From a release

<Steps>

1. Open the [latest release](https://github.com/nWidart/mortise/releases/latest).

2. Download the archive for your platform and the sums file `Mortise-vX.Y.Z-SHA256SUMS.txt`, into the
   same folder.

   | Platform | File |
   |---|---|
   | Linux, x86_64 | `mortise-vX.Y.Z-linux-x86_64.tar.gz` |
   | Linux, arm64 | `mortise-vX.Y.Z-linux-arm64.tar.gz` |
   | macOS, Apple silicon | `mortise-vX.Y.Z-macos-arm64.zip` |
   | Windows, x64 | `mortise-vX.Y.Z-windows-x64.zip` |

   The Linux binaries are static: they run on any Linux of their architecture.

3. Check the SHA-256 sum as in step 3 above, with the name of the archive.

4. Unpack the archive and put `mortise` (`mortise.exe` on Windows) in a folder on your `PATH`.

   <Tabs syncKey="os">
   <TabItem label="macOS">
   ```sh
   unzip mortise-vX.Y.Z-macos-arm64.zip mortise
   sudo mv mortise /usr/local/bin/
   ```
   The binary is signed with a Developer ID and notarized by Apple. A bare binary cannot hold the
   ticket, so macOS checks it online the first time it runs.
   </TabItem>
   <TabItem label="Windows">
   In PowerShell:
   ```powershell
   Expand-Archive mortise-vX.Y.Z-windows-x64.zip -DestinationPath "$env:LOCALAPPDATA\mortise"
   ```
   Then add that folder to your `PATH`. The binary is not signed.
   </TabItem>
   <TabItem label="Linux">
   ```sh
   tar -xzf mortise-vX.Y.Z-linux-x86_64.tar.gz mortise
   sudo mv mortise /usr/local/bin/
   ```
   The binary is not signed.
   </TabItem>
   </Tabs>

5. Run `mortise --version`. It prints the version of the release.

</Steps>

### With cargo

On any platform with a Rust toolchain (Rust 1.99 or later):

```sh
cargo install --locked mortise-cli
```

To build it from a clone instead, see [Build Mortise from source](/mortise/how-to/build-from-source/#build-the-command-line-tool).
